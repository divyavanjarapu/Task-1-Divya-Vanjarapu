# Data Cleaning and Preprocessing

## Project Overview
This project focuses on cleaning a raw dataset and preparing it for analysis. The dataset was processed by handling missing values, removing duplicate records, correcting data types, and standardizing text data.

## Objective
- Handle missing values.
- Remove duplicate records.
- Convert date columns to proper datetime format.
- Clean and standardize text data.
- Prepare a high-quality dataset for analysis.

## Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Steps Performed
1. Loaded the dataset.
2. Identified missing values.
3. Filled numerical missing values using median.
4. Filled categorical missing values using mode.
5. Removed duplicate records.
6. Converted date columns automatically.
7. Cleaned text columns by removing extra spaces.
8. Verified data quality after cleaning.
9. Exported the cleaned dataset.

## Key Features
- Automated date column detection.
- Missing value treatment.
- Duplicate removal.
- Data type correction.
- Text standardization.

## Output
A cleaned dataset ready for data analysis, visualization, and machine learning tasks.
